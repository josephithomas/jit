# Evergreen Developer Skills

Timeless software engineering fundamentals that outlast transient frameworks.

## Core Fundamentals
1. **Clean Architecture**: Separation of concerns, dependency inversion, explicit domain boundaries.
2. **Testing Pyramid**: High-density unit tests at the base, focused integration tests in the middle, and minimal end-to-end smoke tests at the top.
3. **Refactoring Discipline**: Never mix refactoring with feature delivery. Keep automated tests passing at every commit.
4. **Resilience Engineering**: Implement circuit breakers, idempotency keys, and graceful fallbacks for all distributed interactions.
