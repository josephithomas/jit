# Awesome LLM Apps

Architectural patterns and working implementations of real-world AI applications.

## Focus Areas
- **RAG Architectures**: Hybrid search (Dense Vector + BM25), reranking, chunking strategies, and query expansion.
- **Autonomous Agents**: Goal decomposition, scratchpad reasoning (ReAct), and tool execution loops.
- **Multimodal Workflows**: Audio, vision, and document understanding pipelines.
