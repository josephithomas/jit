# WShobson Agents Marketplace

Cross-platform harness configurations and agent adapters.

## Patterns
- **Harness Portability**: Write skills using standard markdown and prompt instructions so they function identically across Antigravity, Claude Code, Codex, and Cursor.
- **Rule Composition**: Modularize repository instructions (`AGENTS.md`, `CLAUDE.md`, `.cursorrules`) to avoid prompt bloat.
