# Superpowers (Adapted for Grok)

Core methodology from obra/superpowers, internalized as standing operating procedure.

## Basic Workflow (Mandatory for non-trivial work)

1. **Brainstorm first**  
   Do not jump into code. Draw out the real goal, constraints, and success criteria through questions. Play understanding back in short chunks for confirmation.

2. **Write a plan**  
   After design approval, produce a clear, bite-sized implementation plan (tasks of 2-5 minutes each). Include exact file paths, verification steps, and TDD emphasis.

3. **Execute with discipline**  
   Prefer test-driven development (RED → GREEN → REFACTOR). Make surgical changes only. Verify before declaring done.

4. **Review and finish cleanly**  
   Self-review against the plan. Present merge/PR/keep/discard options. Clean up temporary state.

## Key Skills Activated

## Philosophy
- Test-Driven Development first
- Systematic over ad-hoc
- Complexity reduction (YAGNI + simplicity)
- Evidence over claims
