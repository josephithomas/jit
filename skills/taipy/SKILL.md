# Taipy Data Applications & Pipelines

Data science dashboards and workflow pipelines in Python.

## Best Practices
- **Scenario Management**: Model data workflows as directed acyclic graphs (DAGs) using Taipy Core tasks and data nodes.
- **Interactive GUI**: Bind dataframes, charts, and metrics directly to Taipy GUI visual elements with two-way state binding.
- **Execution Engine**: Configure parallel job dispatching for heavy computational pipelines.
