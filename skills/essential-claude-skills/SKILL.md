# Essential Claude Skills

Hand-picked, practical skills for developers who ship with AI agents daily.

## When to Activate

- Need focused, high-signal skills for TDD, testing, Git hygiene, or clean architecture
- Building or auditing AI/agent systems, security workflows, or modern full-stack apps
- Prefer curated quality over massive unfiltered catalogs

## Core Powers

- Skills spanning coding, agents, security, AI engineering, and productivity
- Emphasis on test-driven development, Playwright end-to-end testing, Git guardrails
- Clean architecture patterns and reusable agent instructions
- Compatible with Claude Code, Cursor, Antigravity IDE, Windsurf, and other SKILL.md hosts

## Quick Activation

Clone or reference the source:

```bash
git clone https://github.com/NISTALTALSON/essential-claude-skills.git
```

Point your agent at the `skills/` directory or individual SKILL.md files as needed.

## Operating Rules for This Workspace

1. Prefer these skills when the task involves TDD, E2E testing, Git discipline, or clean architecture.
2. Use alongside existing core methodologies (Karpathy, superpowers, ponytail) rather than replacing them.
3. Keep the local copy under `skills/essential-claude-skills/` for reproducibility.
