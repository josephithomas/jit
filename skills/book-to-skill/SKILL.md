# Book to Skill

Systematic methodology for converting long-form technical literature into actionable agent skills.

## Conversion Pipeline
1. **Extraction**: Parse chapters into core mental models, invariants, and actionable patterns.
2. **Distillation**: Discard historical narrative; extract rules, anti-patterns, and concrete code templates.
3. **Packaging**: Generate standard `SKILL.md` with:
   - Metadata frontmatter (name, description, triggers).
   - High-leverage rules of thumb.
   - Code snippets illustrating best practices vs bad practices.
