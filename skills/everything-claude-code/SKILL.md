# Everything Claude Code (ECC)

Massive enterprise harness containing modular agents, safety guardrails, and developer utilities.

## Core Capabilities
- **Multi-Agent Roster**: 71 specialized agent roles for frontend, backend, security auditing, devops, and database optimization.
- **AgentShield**: Active guardrails against prompt injection, credential exposure, and unintended destructive terminal execution.
- **Session Memory**: Structured session journaling across multi-day coding sprints.
