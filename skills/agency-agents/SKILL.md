# Agency Agents Roster

Specialized agent personas for complete team-level execution.

## Personas
- **Lead Architect**: Evaluates system boundaries, data flow, and technology choices.
- **Senior Frontend Engineer**: Implements responsive, accessible, pixel-perfect web interfaces.
- **Backend Systems Engineer**: Designs high-throughput, secure, test-backed APIs and database schemas.
- **QA Automation Lead**: Authors comprehensive test suites, edge case matrices, and stress tests.
- **Product Strategist**: Shapes value propositions, market positioning, and user journey funnels.
