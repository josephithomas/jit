# Cognee Memory Platform

Persistent long-term memory and knowledge graph reasoning for AI agents.

## Core Mechanisms
- **Hierarchical Knowledge Graph**: Extract entities and relationships from user conversations and files into structured triples.
- **Context Synthesis**: Retrieve relevant episodic and semantic context before answering questions or generating code.
- **Memory Consolidation**: Periodically prune duplicate nodes, resolve entity references, and summarize obsolete interactions.
