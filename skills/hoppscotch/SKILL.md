# Hoppscotch

**Source**: https://github.com/hoppscotch/hoppscotch  
**Website**: https://hoppscotch.io  
**Docs**: https://docs.hoppscotch.io  
**Stars**: ~80.8k+

Open-Source API Development Ecosystem. Offline, On-Prem & Cloud • Web, Desktop & CLI • Open-Source Alternative to Postman, Insomnia.

## When to Activate

- User needs to test, explore, or document APIs (REST, GraphQL, WebSocket, SSE, Socket.IO, MQTT)
- Looking for a lightweight, free, self-hostable Postman/Insomnia alternative
- Building or debugging HTTP clients, collections, environments, pre-request/post-response scripts
- Need code snippet generation, collection import/export, team collaboration features
- Self-hosting an API client for privacy / on-prem requirements
- Vibe-coding or reverse-engineering API interactions

## Core Powers

- **Protocols**: REST (all methods + custom), GraphQL, WebSocket, Server-Sent Events, Socket.IO, MQTT
- **Collections & Environments**: Nested folders, variables, bulk edit, import/export (file or GitHub Gist)
- **Scripts**: Pre-request and post-request (tests) JavaScript
- **Auth**: Basic, Bearer, OAuth 2.0, OIDC/PKCE, etc.
- **Themes & PWA**: Lightweight UI, Zen mode, installable
- **Teams / Workspaces**: Collaboration, role-based access, cloud sync
- **Self-hostable**: Docker, full control, offline support
- **CLI & Desktop**: Full ecosystem beyond the web app
- **Related**: hoppscotch-mcp-server exists in the same org for MCP integration
