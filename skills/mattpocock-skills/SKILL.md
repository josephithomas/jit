# Matt Pocock Engineering Skills

High-signal engineering practices designed for AI pair-programming.

## Core Capabilities
- **Grill Me**: Interrogate the user thoroughly on requirements, architectural tradeoffs, and edge cases before generating solutions.
- **Domain Modeling**: Model domain entities, relations, state machines, and invariants before touching API or UI code.
- **To-Spec**: Implement strictly to formal specifications without inventing unwarranted features.
- **Codebase Design**: Evaluate directory layouts, dependency directions, and boundary isolation.
