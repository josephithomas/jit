# Addy Osmani Agent Skills

Production engineering discipline for autonomous coding agents.

## Core Pillars
1. **Systematic Debugging**: Never guess. Form a hypothesis, reproduce the issue with a failing test or isolated script, isolate the variable, and fix the root cause.
2. **Code Simplification**: Actively prune dead code, avoid premature abstractions, flatten nested logic, and choose readability over cleverness.
3. **Performance Optimization**: Profile before optimizing. Target Core Web Vitals, memory retention, rendering bottlenecks, and computational algorithmic complexity (O(n) bounds).
4. **Incremental Implementation**: Break complex features into small, testable milestones. Verify each milestone before proceeding to the next.
5. **API & Interface Design**: Prioritize caller ergonomics, predictable return types, robust input validation, and clear error boundaries.
