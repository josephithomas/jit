# Single skills centre

**Repository:** [josephithomas/jit](https://github.com/josephithomas/jit)

## Rule

There is only one place for skills:

```
skills/<skill-name>/SKILL.md
```

Do not create parallel skill trees at the repo root or in other folders.

## Titus SkillForge

Skill creator tool + skill definition:

```
skills/titus-skillforge/
```

Generated skills from SkillForge must also be written under `skills/<name>/`.

## Free Claude Code

Referenced skill folder:

```
skills/free-claude-code/
```

Upstream project: https://github.com/Alishahryar1/free-claude-code

Claude-compatible skills work with FCC via the same `~/.claude/skills/` install path.

## Standing instructions

Use this repository for skill cloning, working space, and storing content.
