# Scientific Agent Skills

Validated workflows and domain tools for scientific computation, bioinformatics, chemistry, and literature synthesis.

## Core Capabilities
- **Literature & Citation**: Systematically query PubMed, arXiv, and CrossRef; cross-verify citations before assertions.
- **Data Analysis**: Robust statistical workflows using NumPy, SciPy, Pandas, Biopython, and Astropy.
- **Reproducibility**: Parameterize all experiment scripts, pin dependency seeds, and output structured tabular/JSON artifacts alongside raw figures.
- **Validation**: Compare computational outputs against known analytical baselines or literature controls.
