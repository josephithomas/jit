# Distilly

Framework for extracting human intuition and heuristics into reproducible agent workflows.

## Process
1. **Interview / Observation**: Capture expert decisions across challenging real-world scenarios.
2. **Causal Edge Mapping**: Identify what signals caused which choices (Cause -> Effect -> Rule).
3. **Skill Codification**: Format the heuristics into clear `IF <condition> THEN <action> BECAUSE <rationale>` rules.
