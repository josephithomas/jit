# Awesome Claude Code

Curated directory of high-leverage workflows and configurations for terminal-first AI coding.

## Workflow Patterns
- **Session Scoping**: Scope sessions to specific feature branches or bug tickets.
- **Compact & Checkpoint**: Periodically summarize trajectory context to prevent attention degradation on long-running tasks.
- **Scripted Verification**: Pair prompt instructions with automated test triggers (`pytest`, `npm test`, `cargo test`) for autonomous verification loops.
